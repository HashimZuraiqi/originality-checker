# API reference

The complete, always-current contract is generated by FastAPI:

- Interactive docs (Swagger UI): `http://localhost:8000/api/docs`
- ReDoc: `http://localhost:8000/api/redoc`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`

## Conventions

- **Authentication**: `POST /api/auth/register` or `/api/auth/login` sets an
  HttpOnly, SameSite=Lax session cookie (`oc_session`, Secure when
  `COOKIE_SECURE=true`). Every other endpoint except `/api/health` and
  `/api/auth/session` requires it.
- **CSRF**: state-changing requests (POST/PUT/DELETE) must send the
  `X-CSRF-Token` header with the token returned by `/api/auth/me`,
  `/api/auth/session`, register or login.
- **Errors**: JSON `{"detail": "human-readable message"}` with a meaningful
  status (400 invalid input, 401 not signed in, 403 bad CSRF token, 404 not
  found *or not yours*, 409 conflict, 413 too large, 429 rate limited,
  503 optional service unavailable).
- **Ownership**: resources owned by another user always return 404.
- **Rate limits** (per instance): registration 10/hour/IP, login 20/10 min/IP
  and 8/10 min/email, uploads 30/hour/user, rewrites 60/hour/user.

## Typical flow

```bash
B=http://localhost:8000
# 1. Create an account (stores the session cookie in cj, prints the CSRF token)
curl -s -c cj -H 'Content-Type: application/json' \
  -d '{"name":"Ada","email":"ada@example.org","password":"CorrectHorse9Battery"}' $B/api/auth/register
CSRF=...   # csrf_token from the response

# 2. Upload a file (or -F text=... to paste text); analysis starts automatically
curl -s -b cj -H "X-CSRF-Token: $CSRF" -F file=@essay.pdf $B/api/documents
# -> {"document": {...}, "job": {"id": "...", "stages": [...]}}

# 3. Poll progress until status is "completed" (report_id is then set)
curl -s -b cj $B/api/jobs/<job_id>

# 4. Fetch the report, or export it
curl -s -b cj $B/api/reports/<report_id>
curl -s -b cj -o report.pdf "$B/api/reports/<report_id>/export?format=pdf"
```

## Upload options

`POST /api/documents` accepts multipart form fields: `file` **or** `text`,
optional `title`, `author_name`, `collection_id`, and `options` (JSON):

```json
{"min_match_words": 8, "exclude_quotes": true, "exclude_bibliography": true,
 "external_search": true, "semantic": true}
```

## Report structure (abridged)

```text
summary        similarity_index, unattributed_pct, semantic_pct, quoted_pct,
               ai_verdict, ai_label, quality_score, citation_issues, coverage_gap
text           normalised document text; all offsets refer to it
similarity     scores, findings[] (category, method, score, start/end, source_id,
               source_excerpt, citation_detected, counts_toward_index,
               explanation, next_steps, evidence), sources[], method (formula,
               thresholds, provider)
ai             verdict, label, score + score_note, features[] with contributions,
               paragraphs[], caveats[], model metadata
quality        score, subscores, formulas, readability, findings[]
citations      style, citations[], references[] (with Crossref verification), issues[]
coverage       providers[] (status, queries, results, errors), summary,
               not_covered[], data_shared
queries        every query sent to an external service
timings        seconds per stage
```

## Endpoints

### Auth

| Method | Path | Description |
|---|---|---|
| `POST` | `/api/auth/login` | Login |
| `POST` | `/api/auth/logout` | Logout |
| `GET` | `/api/auth/me` | Me Endpoint |
| `POST` | `/api/auth/register` | Register |
| `GET` | `/api/auth/session` | Like /me, but answers 200 for anonymous visitors ({"authenticated": false}). |

### Documents

| Method | Path | Description |
|---|---|---|
| `GET` | `/api/documents` | List Documents |
| `POST` | `/api/documents` | Upload a file (PDF, DOCX, TXT) or paste text; analysis starts automatically. |
| `DELETE` | `/api/documents/{doc_id}` | Delete Document |
| `GET` | `/api/documents/{doc_id}` | Get Document |
| `POST` | `/api/documents/{doc_id}/analyze` | Reanalyze |
| `GET` | `/api/documents/{doc_id}/report` | Latest Report |
| `GET` | `/api/documents/{doc_id}/text` | Get Document Text |
| `GET` | `/api/jobs/{job_id}` | Get Job |
| `POST` | `/api/jobs/{job_id}/cancel` | Cancel Job |
| `GET` | `/api/reports/{report_id}` | Get Report |
| `GET` | `/api/reports/{report_id}/export` | Export Report |
